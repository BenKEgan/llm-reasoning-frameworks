# Primitives (v0.1)

## Reasoning Channels
A datum is admitted as-is and placed into one or more channels.

1. When (temporal relevance): persistent / recurring / episodic / transient
2. Pressure (load/intensity): negligible / moderate / dominant
3. Control (constraint rigidity): loose / guided / enforced / forced
4. Clarity (predictability of correct action): clear / mostly clear / ambiguous / conflicting
5. Variance (behavior spread): tight / moderate / wide
6. Salience (risk attention): low / elevated / dominant
7. Persistence (structural vs incidental): persistent / recurring / incidental

## Evidence Polarity Tag (EPT)
- outcome: recorded crashes/injuries/fatalities (lagging)
- perception: reports/complaints/near-miss narratives (leading, behavior-shaping)
- structural: geometry/infrastructure exposure (persistent)
- operational: construction/events/temporary disruptions (episodic modifiers)

## Perception Signal Strength (PSS)
- isolated: one report, no corroboration
- clustered: multiple reports, same location/concern
- patterned: clustered + aligns with known risk archetypes
- systemic: patterned + supported by broader archetype evidence

## Outcome Data Reliability (ODR)
A modifier capturing how complete/representative “official” records are likely to be.
- high / medium / low

Triggers for lowering ODR include known underreporting dynamics, narrow reporting windows, or mismatched data sources.

## Inferred Temporal Window (ITW)
Use only as an interval, never a point time.

ITW := [start–end] + confidence + driver_type

driver_type:
- institutional_schedule
- commuter_norm
- construction_window
- event_window

## Comparative Structural Reference (CSR)
A comparison statement becomes a hypothesis generator only if it names a mechanism.

CSR outputs questions, never conclusions.
